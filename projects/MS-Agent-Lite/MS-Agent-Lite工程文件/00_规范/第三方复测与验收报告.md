## 四、L5 UI 实测

### 4.1 冒烟结果（页面初始状态）
- 页面渲染正常，标题"面试助手Agent（MS-Agent） · 面板"；全程无 JS 报错。
- 能力选择（文本+视觉/多模态/文本+OCR）、岗位名输入、JD 双入口、参考网址动态行、简历上传、一键配置、生成按钮均存在。
- 小白引导文案丰富（API Key 获取指引、文件名规则预提示、简历格式与"传文字版"提示、JD 粘贴图片拦截提示等）——**引导质量：优**。

### 4.2 新发现问题（本轮复测发现 → 已当场修复）
| 编号 | 问题（复现步骤） | 严重度 | 修复 |
|------|------|------|------|
| U1 | 岗位名输入 `..` 无任何提示（仅提交后才报错，且前端正则允许 `.`/`..`、后端拒绝——前后端不一致） | 中 | app.js 加 input 实时校验，正则与后端一致（拒绝 `.`/`..`），红框 + title 即时提示 |
| U2 | 参考网址输入 `http://127.0.0.1:8900/` 无预检（只查 http(s) 前缀，提交后后端才拒） | 中 | app.js 新增 `isLocalUrl()`（与后端 isBlockedHost 同规则），URL 失焦/提交/JD 读取入口三处统一拦截 |

### 4.3 修复复测
- 输入 `..` → 立即红框 + title"不能是 . 或 .."；清空/正常输入"腾讯" → 提示消失。✅
- 输入 `http://127.0.0.1:8900/` 失焦 → 红框 + "本机/内网地址，无法读取"；输入 `https://www.baidu.com` → 放行。✅

## 五、风险残留与改进建议（按优先级）

### 高优先级（建议下一迭代做）
| 项 | 说明 | 建议 |
|----|------|------|
| R1 | 任务状态纯内存，服务重启丢任务 | 任务 JSON 落盘 `_task.json`（已在评估报告 D6 提出，未实施） |
| R2 | `isBlockedHost` 对公网域名解析到内网 IP 的最终跳转无法在 Node 纯解析层拦截 | 建议限制 redirect 后重校验目标 host，或改为"抓取代理/白名单域名"模式（低优先级安全增强） |

### 中优先级（体验优化，面向小白）
| 项 | 说明 | 建议 |
|----|------|------|
| R3 | 参考网址校验只在 blur 触发，纯键盘流（Tab 连续输入）可能短暂保留红框 | 可改为 input 事件+延迟校验，或保留现状（blur 语义合理） |
| R4 | 配置页 API Key 输入无"粘贴即校验长度"的即时提示 | 加 input 监听：<5 字符时提示"Key 太短，请确认完整粘贴" |
| R5 | 生成按钮在无任何输入时可直接点击（点后给出错误提示） | 输入不足时按钮置灰 + 说明缺哪项（更符合小白预期） |

### 低优先级
| 项 | 说明 | 建议 |
|----|------|------|
| R6 | verify.js 的 GLOSSARY 平衡括号扫描对极端嵌套仍可能误判 | 增加失败降级（解析失败按空词表处理并告警） |
