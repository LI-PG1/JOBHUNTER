1认识面试准备助手

先用 30 秒搞懂它能干什么，再动手装。

  • 输入：你的简历（pdf / word / txt / markdown）+ 岗位 JD（职位介绍）+ 可选的参考网址 / 参考信息（面经、公司背景、技术文章等文字）
  • 输出：一份完整的「岗位名称+面试准备.html」网页材料（自我介绍、项目深挖、技术题库、反问环节等 8 个部分）
  • 工作方式：你配置的大模型负责生成内容，面试准备助手在本地处理文件与网页、生成并预览材料
  • 适合谁：零编程经验也能装。需要准备 3 样：Windows 电脑、一个或两个大模型 API Key（第 2 步教怎么拿）、项目文件（第 3 步下载）

整体流程一览

拿 API Key → 下载项目 → 双击 启动面试准备助手.bat（首次自动解压内置运行环境） → 浏览器自动打开 → 填 API Key → 上传简历 + 填 JD → 一键生成 → 审核通过 ✓
📌 全程不需要写代码、不需要自己安装 Node.js。遇到问题先看第 7 步 FAQ，或按错误提示操作。

  2. 新用户注册即送免费额度，无需绑定银行卡
  3. 进入「API Keys」，点「Create API Key」，起个名字（如 ms-agent）
  4. 生成后立即复制——Key 只显示一次，关闭就看不到了

4启动面试准备助手

以后每次使用都这样做：双击启动器 → 浏览器自动打开。无需自己安装 Node.js。

✅ 双击启动器（最简单） —— 打开发布包第一层（项目根目录）D:\MS-Agent-Lite，找到 启动面试准备助手.bat，双击即可。首次启动会自动解压内置的 Node.js 与依赖包（约 1~2 分钟，仅此一次，期间不要关窗口），随后自动启动本地服务并打开浏览器 http://localhost:8900/；若没自动打开，手动访问 http://127.0.0.1:8900 即可。之后每次启动都是秒开。
💻 手动方式（可选）：如果你已经自行安装了 Node.js，也可以在终端进入 MS-Agent-Lite工程文件\20_执行 后运行 npm start（首次需先 npm install）。
✔ 检查：看到 服务已启动: http://127.0.0.1:8900 字样即成功。
⚠ 用完想关闭：双击启动的服务在后台运行，直接关浏览器即可（下次双击自动复用/重启）；手动方式启动的回到终端按 Ctrl + C（问 Y/N 就按 Y 回车）。

5把 API Key 填进面试准备助手

面试准备助手已经把"配钥匙"做成了主页面第 1 步，照着填即可：

打开面试准备助手页面 → 第 1 步「大模型 API Key」→ 选平台（自动填 Base URL / 模型）→ 粘贴 Key → 保存并自检 → ✓ 配置成功
  1. 先做第 4 步启动面试准备助手，浏览器打开 http://127.0.0.1:8900
  2. 页面顶部就是第 1 步「大模型 API Key」卡片：在「选择平台」里选你第 2 步注册的服务商（如智谱 AI），名称 / Base URL / 模型会自动填好
  3. 把第 2 步复制好的 API Key 粘贴到「⑥ API Key」输入框
  4. 点「💾 保存并自检」→ 显示「✓ 已保存并自检通过」、顶部状态条变绿「✓ API Key 已配置成功」即成功
📌 能力选择：本版只需文本能力（界面默认「文本能力模型」即可），识图由面试准备助手内置的本地离线识别自动处理，无需视觉模型。备选：直接编辑 D:\MS-Agent-Lite\MS-Agent-Lite工程文件\20_执行\config.json 里的 apiKey（注意保留英文引号），拿不准就用页面方式。

6开始使用（6 步走一遍）

按界面提示操作即可：

上传简历 → 选行业（可选）→ 填岗位名称 → 填岗位 JD（直接粘贴文本）→ 补参考网址 / 参考信息（可选）→ 一键生成 → 审核通过 ✓
  1. 上传简历：支持 pdf / word(docx) / txt / markdown(md)，请上传文字版（扫描件、拍照或图片型 PDF 无法读取，请先用 Word 打开后另存为 docx，或转成 txt）——拖进去或点选择，解析成功会显示预览
  2. 选行业方向（可选）：如「程序员/开发」，界面会提示常搜网站
  3. 填岗位名称：如 腾讯-Agent开发实习生（生成文件名 = 岗位名称 + 面试准备）
  4. 填岗位 JD：把招聘页面的 JD 文字直接粘贴进文本框——文字越完整，生成的材料越贴合岗位；链接读取（点「读取到下方」）仅为辅助方式，若信息读取失败请直接粘贴文本
  5. 补充参考网址（可选）：公司官网 / 面经 / 技术文章，可点「＋ 添加一行网址」填多条
  6. 补充参考信息（可选）：面经、公司背景、技术文章、发展方向等文字直接粘贴（多段用空行隔开，最多 20000 字，有字数提示）——网页打不开时把内容复制粘贴到这里同样有效
  7. 点「🚀 一键生成面试材料」→ 等 3~10 分钟 → 看到「内容审核 ✓ 通过」+ 预览窗口

它要花多少钱

省钱机制：需要付费的只有「大模型 API」一项，且按实际消耗的 token 计费——不生成就不花钱。识别图片文字、组装网页等重活都在你本机完成（本版内置本地离线识别，不消耗 token）；每次只在你点「🚀 一键生成面试材料」时调用模型，输入为简历 / JD / 参考信息 / 8 个生成提示，输出为 8 份材料正文与内容审核。

预期花费：一次完整生成约消耗 15 万 tokens（约合 15 万字的输入与输出总量），按 DeepSeek-V4-flash 官方现价（输入 1 元 / 百万 tokens、输出 2 元 / 百万 tokens）约 0.2 元；工作日高峰时段（9:00–12:00、14:00–18:00）价格约翻倍至 0.4 元。用智谱 glm-4-flash（长期免费）时几乎为 0。DeepSeek 官方已公告近期将上调定价，实际费用以最新官方价格为准；相比交给人工整理的时间成本，用模型生成的边际成本可忽略。

用量建议：参考网址不超过 10 条、简历不超过 10 页，可把输入 token 控制在低区间；每份材料生成后如对个别文件不满意，用「重试」单独重新生成该文件，不必整轮重跑，从而避免重复计费。联网搜索（可选增强）只消耗搜索服务的免费额度（Tavily 每月 1000 次），不产生大模型费用。

7常见问题（FAQ）

点开任意问题查看答案。

为什么需要 1 个或 2 个 API Key？
生成面试材料只需要 1 个支持文本（text）的模型 Key，例如智谱 glm-4-flash 或选 DeepSeek-V4-Flash（页面选择模型时自动填好配置）。图片 / 扫描件中的文字由面试准备助手内置的本地离线识别自动处理，无需视觉模型。
材料里出现【待联网核实：…】标注怎么办？
这是正常现象：大模型的知识存在截止日期，遇到「当前时间 / 实时数据 / 最新动态」等时效信息时，AI 会按协议在正文标注【待联网核实：具体问题】、在文件末尾列出「联网核实清单」，并在生成完成后的结果页汇总提示——这些信息未经联网确认，建议核对来源后再引用。两种处理方式：① 配置联网搜索（可选增强）：在「⚙ 高级设置」里填写搜索服务 Key（Tavily，免费注册，每月 1000 次），下次生成前会自动搜索权威来源并注入上下文，减少标注项；② 在「补充参考网址」里粘贴权威来源链接后重新生成，让 AI 直接以你的材料为准。
首次启动解压依赖报错 / 很慢怎么办？
首次启动会自动解压内置的 Node.js 与依赖包（约 1~2 分钟，仅一次，依赖来自发布包内置压缩包、不依赖网络）。若解压中断或报错，可删除 runtime\node 与 MS-Agent-Lite工程文件\20_执行\node_modules 后重新双击启动器，重试基本都能成功。
启动时提示 8900 端口被占用？
上次没关干净。回到旧终端按 Ctrl + C；或按 Ctrl+Shift+Esc 打开任务管理器，结束所有 node 进程后重试。
浏览器打不开 http://127.0.0.1:8900？
确认启动的黑色窗口还开着且没报错；确认地址是 http 而不是 https。
点生成后提示「没有可用 provider」？
第 5 步没配好：检查 Key 是否粘贴、「能力选择」是否含文本能力（默认「文本能力模型」即可）、有没有点「保存并自检」。配置后看到顶部状态条变绿「✓ API Key 已配置成功」即正常。
上传简历提示「不支持格式」？
只支持 pdf / docx / txt / md。老式 .doc 请另存为 .docx 或转 PDF；图片型简历需先转成带文字层的 PDF。
JD 信息读取失败？
部分网站会限制程序读取内容，导致无法从链接获取 JD。建议直接打开招聘页全选复制，把 JD 文本粘贴进文本框（这也是更准确、处理更快的方式）。链接读取仅作为辅助。
链接读取会被封号吗？
不会。本项目只在你点「读取到下方」时访问一次该网页（最多自动重试一次），不会批量抓取、不会轮询、不会访问你没填写的网址，属于正常浏览行为，不存在封号风险。若某网站频繁读取失败，直接粘贴文本即可。
生成很慢 / 某个文件失败？
正常，免费模型较慢。失败的文件会显示「重试」按钮，点一下单独重试即可，不影响其他文件。
审核提示 WARN？
说明生成内容里可能有数字 / 项目与你的简历对不上。按提示人工修正对应文件后重新生成。
界面或日志中文乱码？
不影响使用。若在意：在终端标题栏右键 → 属性 → 字体选「新宋体」或 Lucida Console。
