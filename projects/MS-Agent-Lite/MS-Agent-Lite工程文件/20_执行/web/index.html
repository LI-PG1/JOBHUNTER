⚙ 高级设置（多模型配置管理）

使用说明：本页是统一管理全部模型配置与 API Key 的核心界面。主页面第 1 步每次保存一个配置（保存后「大模型 API Key」输入框自动清空，便于继续配置下一个），保存后的配置会自动出现在下方列表里；支持多平台备用切换、多个文本模型、启停 / 删除 / 单独自检。生成面试材料至少需要 1 个已启用且含文本能力的配置；列表顺序即调用优先级（排在上面的优先使用）。

新增 / 编辑配置

必须包含 text 才能用于生成面试材料；vision 为可选（本版识图由本地离线识别完成，视觉模型仅作备用）。
配置保存后自动生效；列表顺序即调用优先级（排在上面的优先使用）。生成面试材料至少需要 1 个已启用、含文本能力且 Key 有效的配置。

本地图片文字识别

软件自带的离线图片文字识别：无需联网、无需额外安装，可直接提取图片 / 扫描件中的文字。本版识图由本地识别完成：图片文字提取顺序为本地识别 → 本机工具 → 视觉模型（若配置）。

本地工具（可选增强）

在本机安装文档解析 / 图片识别工具，可降低大模型用量、增强离线图片文字识别。全部为可选：未安装时自动回退原有流程，不影响生成。

联网搜索（可选增强）

大模型的知识存在截止日期。生成材料时，AI 遇到「当前时间 / 实时数据 / 最新动态」等时效信息会按协议在正文标注【待联网核实】，并在结果页汇总清单提示人工确认；配置搜索服务 Key 后，生成前会自动搜索权威来源并注入生成上下文，减少标注项。全部为可选：不配置时按协议标注，不影响生成。
