# 面试跟踪助手工作区

> 你的面试进度跟踪 + 岗位投递排序助手。
> 工作区：`D:\TRAE\WORKSPACE\面试跟踪助手`（所有生成文件都在此目录下）

## 我的两个职责

### 1. 记录并跟踪面试进度
你把投递/笔试/面试情况告诉我（一句话即可，如「今天投了字节 AIGC 岗」「下周一面」），我会：
- 更新 `10_面试跟踪/投递总表.md`（全局一览：状态、当前环节、下一动作）
- 在 `10_面试跟踪/<公司名>/跟踪记录.md` 里写详细时间线与复盘
- 主动帮你盯节点：提醒笔试时间、面试时间、跟进下一动作

### 2. 同公司多岗位排序
有些公司单次只允许投递有限个岗位（常见 1~2 个）。你把该公司多个岗位的链接或 JD 发给我，我根据你的简历：
- 逐岗分析匹配度（技能/经历/方向/证据/硬性条件五维评分）
- 输出排序表 + 建议使用的简历版本（A=AI开发工程师 / B=AI推理部署工程师）
- 结果存在 `20_岗位排序/<公司名>-岗位排序.md`

## 面试跟踪助手（30_应用）与文档的关系

- **数据源**：`10_面试跟踪/投递总表.md`（我维护）→ 与 `30_应用/data/投递数据.json`（你自助维护）双轨并存。你随时可在应用里自助新增/更新；告诉我进展时我同步更新两侧。
- 应用页面「按简历匹配度排序」入口读取 `20_岗位排序/` 下文档。

## 怎么用我

| 你想做什么 | 对我说 |
|-----------|--------|
| 投了新岗位 | 「投了 <公司> 的 <岗位>，链接 xxx」 |

| 拿到结果 | 「<公司> 给我 Offer 了 / 挂了 / 让我等」 |
| 同公司多岗位纠结 | 直接贴多个链接或 JD（可带投递名额限制信息） |
| 看当前进度 | 「现在进行到哪了 / 汇总一下我的投递情况」 |

## 关键约定

- 简历基准以 `01_简历基准/参与边界卡.md` 为准，任何排序分析都基于它，不引入简历之外的编造信息
- 两份简历是**同一段实习**（趋动科技 2026.03–2026.07）的两个侧写，不是两段实习
- 所有记录默认以当天日期为准，你只需说事件，时间由我补全
