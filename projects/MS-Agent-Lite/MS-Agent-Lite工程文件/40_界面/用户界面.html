欢迎使用 面试准备助手

面向技术岗位求职的本地 AI 面试教练：上传简历、粘贴岗位 JD，自动生成覆盖面试前 / 中 / 后全流程的 8 份准备材料，并可随时做「保存并自检」，确保配置可用。

开始使用 → 查看使用指南

1三步开始

与主界面顶部流程条一致：钥匙 → 能力 → 保存验证 →（可选）高级设置

1

配置大模型 API Key

选择平台（支持 12 家主流大模型平台，也可手动填写）→ 粘贴 API Key → 点「保存并自检」。自检通过后状态条变绿，即可开始生成。每次保存一个配置，保存后「大模型 API Key」输入框自动清空，可粘贴下一个平台的 Key 继续配置；所有配置统一在右上角「⚙ 高级设置」中管理，顺序即调用优先级。

2

输入岗位与材料

填写 岗位名称（如 腾讯-Agent开发实习生）→ 上传 简历（pdf / word / txt / md）→ 粘贴或抓取 岗位 JD（可选补充参考网址）。

3

一键生成，直接开用

点击「一键生成」，自动产出 8 份材料：公司背景 / 面试主线 / 自我介绍 / 项目深挖 / 技术场景题 / 反问环节 / 面经题库 / 数字口径，并内置面试前清单、面试中实时笔记与面试后跟进模板。

2为什么用它

专为「准备充分、状态在线」的候选人设计

📋

全流程覆盖

面试前清单核对 → 面试中按环节实时记笔记 → 面试后复盘模板，材料即用即取。

🔌

多模型兼容

智谱 / DeepSeek / OpenAI / 通义 / 千帆 / 混元 / Kimi / 星火 等 12 家平台，支持多配置切换，保存即真实自检。

🔒

本地私密

全程在本机运行，简历与材料只存本地；除调用你配置的大模型接口外，不上传任何数据到其他服务。

开始之前（首次使用请先读）：
  • 先启动 面试准备助手：进入 MS-Agent-Lite工程文件 目录后运行 node 20_执行\server.js，浏览器访问 http://127.0.0.1:8900（详见《使用指南.html》第 8 步）。
  • 还没有 API Key？ 到所选平台官网注册 → 实名认证 → 创建 API Key → 复制（详见《使用指南.html》第 2 步，有各平台获取入口）。
  • 简历建议：上传文字版 PDF 或 Word；若为扫描件/图片型，请先转成文字版再上传，否则生成的材料缺少你的项目经历。
