### 2. 阈值风险发现（重要）

**匹配打分-medium（推理优化岗）得分 25，存在「隐含技能误杀」风险：**
- 该岗位（vLLM/SGLang/KV Cache/量化/K8s）与候选人研究方向（大模型推理优化）高度相关，但画像卡只显式包含 vLLM，LLM 未从"研究方向大模型应用与推理优化"推断出量化/KV Cache 等隐含技能 → 判 25 分（<60 将被淘汰）
- **根因**：匹配度分母 = 岗位核心技能数，画像卡未补全隐含技能时会被低估
- **对策**：第一层「画像锚定 Gate」的**隐含技能补全机制（标"待确认"）必须强制化**——LLM 需从研究方向/项目经历推断强相关技能并入画像卡，补全后该岗可回到 60+ 分档

### 3. 阈值参数结论

- **80% 收录 / 60-80% 补足标识 / <60% 淘汰 / ≥90% 扩散** 分档设计合理，予以保留
- 前提约束：画像卡质量必须由第一层网关保障（隐含技能补全 + 防幻觉），否则阈值会被画像卡缺陷扭曲
- 推理岗/应用岗的技能线阈值差异暂不拆分（样本不足，待 v0.2 真实数据积累后二次校准）
