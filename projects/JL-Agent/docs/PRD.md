## 1. 产品定位

- **一句话**：本地运行的一键简历生成 Agent —— 输入个人背景 + 目标岗位 JD，生成面向岗位定制、页面填满、内容真实的简历。
- **目标用户**：求职者，以应届毕业生 / 实习申请 / 1-3 年社招技术岗为主。
- **核心场景**：投递前 10-30 分钟，把经历与 JD 交给 简历生成助手 生成可投递简历。
- **价值主张**：一键生成 + 面向岗位定制 + 页面填满 + 真实优先 + 本地单用户零云依赖。
- **差异化**：
  - vs 通用 LLM 聊天：结构化表单 + 强约束（数量/填满/真实），而非自由对话；
  - vs 在线简历工具：本地单用户、AI 按 JD 定向生成而非固定模板；
  - vs 一键生成工具：内置「页面填满 + 真实优先 + 待核实标注」三道防线。
- **非目标**：不做招聘平台投递、不做多用户协作、不做云端账号体系。

## 4. 功能需求（优先级依据 + GWT 验收 + AI 可行性）

> 优先级依据：MoSCoW（P0=Must，P1=Should，P2=Could，P3=Won't this round）+ RICE 补充（见各条）。
> 验收格式：Given-When-Then。

### FR-1 模型配置（对应 contract.md §4.1；R24 落地）

- **描述**：厂商 + 模型双下拉选择；配置名称 / Base URL 由预设自动填充并**隐藏**（防误改）；API Key 占位符随厂商+模型动态展示格式要求；多配置列表按激活优先级排列。
- **优先级**：P0（RICE：影响=生成前置，覆盖=全部用户，成本=低）。
- **验收（GWT）**：
  - Given 用户打开设置控制台且后端正常
  - When 选择「DeepSeek」+「deepseek-v4-flash」
  - Then 隐藏字段自动填充 name=「deepseek · deepseek-v4-flash」、baseurl=「https://api.deepseek.com/v1/chat/completions」，Key 输入框占位符显示 "sk-..."，且界面上不存在可手动编辑 name/baseurl 的可见输入框。
- **AI 可行性**：无 AI 参与（前端映射），确定性实现。

### FR-2 简历信息与校验（contract.md §3；R17/R23 落地）

- **描述**：基本信息 / 教育 / 实习 / 项目 / 技能 / 荣誉 / JD 七大分组，必选与可选标注；教育 1~3、实习 0~2、项目 0~3、技能 1~10、JD 1~5 数量约束；时间限制 2015.01~2030.12；邮箱/电话/枚举校验；保存前必填缺失红框定位。
- **优先级**：P0（RICE：影响=生成前置，覆盖=全部用户）。
- **验收（GWT）**：
  - Given 页面加载且未填任何简历
  - When 点击「保存简历」且姓名为空
  - Then 保存被阻止，姓名输入框出现红框高亮并滚动定位到该字段，提示文案指明缺失项。
  - Given 教育经历已添加 3 条
  - When 点击「+ 添加教育」
  - Then 第 4 条添加被阻止，提示教育最多 3 条。
- **AI 可行性**：无 AI（确定性校验）。

### FR-3 简历生成（contract.md §4.3；P4 落地）

- **描述**：SSE 分板块生成（基本信息/自我评价/教育/实习/项目/技能/荣誉），项目条数按 §3.5 映射零漂移；AI 创造/美化分支；未配置 Key 时阻止并引导；生成完成滚动到预览。
- **优先级**：P0（RICE：影响=产品核心，覆盖=全部用户）。
- **验收（GWT）**：
  - Given 简历已保存、模型 Key 可用、JD 已填
  - When 点击「简历生成」
  - Then 出现进度条并逐板块推进；完成后预览区自动出现简历且页面滚动到预览；教育条数与 §3.5 映射一致。
- **AI 可行性**：强依赖 LLM。**降级**：板块失败标「待补充」；未配置搜索标【待联网核实】；取消可中止（contract.md §4.4 状态机）。

### FR-4 预览编辑与锁定（contract.md §4.6；P6 落地）

- **描述**：点击预览正文文字可编辑条目；已编辑条目带「已锁定」标识并提升 critical 权重；单条重生成只影响目标板块；支持解锁允许 AI 重写。
- **优先级**：P1（RICE：影响=高，覆盖=重度用户，成本=中）。
- **验收（GWT）**：
  - Given 已生成简历
  - When 用户编辑某条正文并保存
  - Then 该条出现「已锁定」标识；再次生成后该条内容不被 AI 覆盖，其余条目正常更新。
- **AI 可行性**：编辑=确定性；锁定/重写由 LLM 按指令执行（可控）。

### FR-5 页面适配（contract.md §6；P5 落地）

- **描述**：一页/两页末页填充度 ≥85%（75%~85% 可接受）；密度档全局生效；≤3 轮收敛；不溢出；收敛失败提示改选页数。
- **优先级**：P0（RICE：影响=差异化卖点）。
- **验收（GWT）**：
  - Given 内容较少导致末页填充度 <75%
  - When 点击「自动适配」
  - Then 系统扩充内容并重排，重复至末页填充度 ≥85%，且最多 3 轮；若仍未收敛则提示改选页数。
- **AI 可行性**：混合（测量=确定性，重写=LLM），收敛控制为确定性策略。

### FR-6 导出（contract.md §4.5；P6/R25a 落地）

- **描述**：水印模式必选（练习水印 / 正式无水印）；AI 项确认清单未勾选阻止导出；导出格式 PDF（浏览器打印）/ DOCX / Markdown / HTML / JSON。
- **优先级**：P1（RICE：覆盖=全部用户，成本=低）。
- **验收（GWT）**：
  - Given 已生成简历且选择 Markdown 格式
  - When 点击「导出」
  - Then 下载 .md 文件，内容为标准 GFM（# 标题 / ## 区块 / - 列表），正文无 HTML 转义残留。
  - Given 已生成简历且选择 HTML 格式
  - When 点击「导出」
  - Then 下载 .html 文件，为完整 HTML5 文档（含 charset/viewport/内嵌打印样式），可独立打开。
- **AI 可行性**：无（模板确定性渲染）。

### FR-7 多配置 + 插件双层启动（contract.md §4.1；R19/R20/R21 落地）

- **描述**：多模型配置按优先级自动切换；插件（OpenCLI/MediaCrawler/Agent-Reach/zhihu-cli/Tavily）「配置」与「启用」分离；一键配置失败给出排查指引；功能模块开关联动。
- **优先级**：P2（RICE：影响=中，覆盖=进阶用户，成本=高）。
- **验收（GWT）**：
  - Given 插件处于「未配置」状态
  - When 点击「启用」
  - Then 启用被禁用并提示先执行一键配置；一键配置失败时给出具体排查指引而非静默失败。
- **AI 可行性**：无（进程/依赖管理）。

### FR-8 引导与可达性（R25 落地）

- **描述**：左栏 4 步流程栏（高亮当前/已完成步骤 + 动态引导行）；右栏常驻提醒栏（聚焦/点击字段显示三段式说明，含动态行与按钮全覆盖）；可选分组默认收起、必选展开；Esc 关闭抽屉/弹窗；空列表有引导指引。
- **优先级**：P1（RICE：影响=新用户激活率，成本=低）。
- **验收（GWT）**：
  - Given 页面加载且尚无简历
  - When 聚焦姓名输入框
  - Then 右栏显示「姓名」说明；左栏当前步骤为第 1 步（配置模型）。
  - Given 高级设置抽屉打开
  - When 按下 Esc
  - Then 抽屉关闭，焦点可继续在页面操作。
- **AI 可行性**：无。

## 5. AI 可行性标注汇总

| 功能 | AI 依赖 | 可行性 | 降级策略 |
|---|---|---|---|
| 生成（FR-3） | 是（LLM） | 高 | 未配置 Key 阻止；板块失败标「待补充」；取消可中止 |
| 联网搜索 | 是（Tavily + 上下文注入） | 高 | 未配置则标【待联网核实】，不影响生成 |
| 页面适配（FR-5） | 部分（重写） | 高 | ≤3 轮收敛，失败提示改选页数 |
| 预览编辑/锁定（FR-4） | 部分（单条重写） | 高 | 已锁定条目永不重写（确定性约束） |
| 配置映射/校验/导出（FR-1/2/6） | 否 | 确定 | — |

## 6. MVP 范围

**in-scope**：本地单用户；配置（多厂商/多模型/多配置）；结构化表单 + 校验；SSE 生成；预览编辑 + 锁定；自动适配填满；五格式导出；插件双层接入；流程/提醒引导与键盘可达性。

**out-of-scope（含理由）**：
- 云端账号 / 多用户协作 —— 与「本地单用户」定位冲突；
- 后端直接出 PDF —— 依赖浏览器打印版式，成熟后（contract.md §7 E8 已注明）；
- 简历投递 / 追踪、AI 面试 —— 超出简历生成边界；
- 移动端深度适配 —— 窄屏隐藏辅助栏（已部分响应式）。
