# 简历生成助手 AI 交互态清单

> 依据《05_UI-UX设计师.md》§一.3「AI 体验特化」交付标准编制。统一格式：状态 / 触发条件 / 展示内容 / 退出逻辑。与 PRD v0.7 §5（AI 可行性标注）呼应；实现位置见各态「实现」。

## 1. 流式输出态（生成推进）

| 项 | 内容 |
|---|---|
| 状态 | 生成中（SSE 板块推进） |
| 触发条件 | 点击「简历生成」且校验通过，任务进入 generating |
| 展示内容 | 渐变进度条（accent→accent-2 渐变）+ 文案「板块完成：xxx」；板块失败追加「（降级）」；阶段文案更新 |
| 退出逻辑 | task.done → 进度 100% + 滚动到预览 + 绿色提示；task.failed → 红色横幅；task.canceled → 「任务已取消」横幅 |
| 实现 | `app.js` SSE `block.done`/`task.done`/`task.failed`/`task.canceled` 监听；`css/app.css` `.progress-bar/.progress-fill` |

## 2. 等待态（AI 思考/联网）

| 项 | 内容 |
|---|---|
| 状态 | 等待（无中间事件或子过程执行中，如深度搜索） |
| 触发条件 | 生成/适配运行期间 |
| 展示内容 | 「生成」/「自动适配」按钮禁用（disabled 视觉弱化）；进度条持续推进；无额外空转动画 |
| 退出逻辑 | 任意终态事件到达即恢复按钮可用 |
| 实现 | `startGenerate()`/`run()` 中按钮 disabled 切换；`resetGenerateBtns()` 恢复 |

## 3. 纠错态（必填缺失定位）

| 项 | 内容 |
|---|---|
| 状态 | 提交被拦截 |
| 触发条件 | 点「保存简历」/「简历生成」时必填字段缺失，或后端校验 422 |
| 展示内容 | 缺失字段红框高亮（.err-inp：红边框 + 红色 glow + 浅红底）+ 页面滚动定位到第一个缺失项 + 横幅列出缺失项 |
| 退出逻辑 | 用户补填后重新提交；红框随重新校验清除 |
| 实现 | `app.js` `checkRequired()`/`locateFirstMissing()`；`css/app.css` `.err-inp` |

## 4. 不确定性表达（AI 无法保证真实）

| 项 | 内容 |
|---|---|
| 状态 | 降级标注 |
| 触发条件 | ① 未配置搜索 Key 且涉及需核实信息 → 标【待联网核实】；② 板块生成失败 → 该板块内容标「待补充」 |
| 展示内容 | 预览正文中的降级标注文本；生成过程提示「（降级）」 |
| 退出逻辑 | 重生成替换标注；补配置搜索 Key 后重新生成消除【待联网核实】 |
| 实现 | 生成引擎降级分支（engine degraded）；前端 SSE 文案追加「（降级）」 |

## 5. 取消态（用户中止）

| 项 | 内容 |
|---|---|
| 状态 | 生成中止 |
| 触发条件 | 生成中点「取消」（btn-cancel 仅在生成期间可用） |
| 展示内容 | 按钮恢复；横幅「任务已取消」；流程栏回退至第 3 步 |
| 退出逻辑 | SSE 连接关闭；可重新发起生成 |
| 实现 | `app.js` 取消分支 + `resetGenerateBtns()`；`setFlow(3)` |

## 6. 未配置态（前置缺失）

| 项 | 内容 |
|---|---|
| 状态 | 功能不可用提示 |
| 触发条件 | 未配置可用模型（无激活 provider）时点生成 / 生成时 Key 失效 401 |
| 展示内容 | 顶栏「配置模型」状态提示 + 横幅引导去设置；401 自检中文文案（Key 无效/过期） |
| 退出逻辑 | 完成模型配置并保存自检通过后恢复 |
| 实现 | `renderProviders()` 状态回显；`humanTestError()` 错误翻译（401/403/404/429/400/超时） |

## 7. 失败态（收敛失败/网络异常）

| 项 | 内容 |
|---|---|
| 状态 | 生成/适配失败 |
| 触发条件 | 适配 ≥3 轮未收敛、网络中断、服务错误 |
| 展示内容 | 红色横幅给出具体原因（含错误码翻译）；适配收敛失败提示改选页数；流程栏回退第 3 步 |
| 退出逻辑 | 修改条件后重试 |
| 实现 | `task.failed` 监听 + `Adapt.showBanner(…, true)`；适配收敛控制 |

## 8. 空态（无数据）

| 项 | 内容 |
|---|---|
| 状态 | 空列表/空预览 |
| 触发条件 | 「我的简历」为空；预览未生成 |
| 展示内容 | 空列表引导文案（「填写上方简历信息并保存…」）；预览占位「生成后在此预览」 |
| 退出逻辑 | 保存首份简历 / 首次生成成功即消失 |
| 实现 | `app.js` `loadList()` 空态分支；`index.html` `.preview-empty` |

## 覆盖核对（规范 §八 KPI：核心任务 100% 覆盖）

| 核心任务 | 流式 | 等待 | 纠错 | 不确定性 | 备注 |
|---|---|---|---|---|---|
| 配置模型（自检） | — | ✓（自检请求中） | ✓（失败原因） | ✓（错误翻译） | — |
| 填写简历（保存） | — | — | ✓（必填红框） | — | — |
| 生成简历 | ✓ | ✓ | ✓ | ✓ | — |
| 预览/适配 | ✓ | ✓ | ✓（收敛失败） | — | — |
| 导出 | — | — | ✓（未生成阻止） | — | 水印必选/确认清单 |
