# 面试准备助手（纯文本版）新手安装使用指南（纯小白版）

> 本指南写给**完全零基础**的朋友：没接触过 Agent、没装过任何编程软件、没配置过任何接口。
> 你只需要：一台 Windows 电脑、能上网、30~60 分钟耐心。
> 每一步都先看「✔ 检查」，确认做对了再走下一步。遇到问题翻到文末「常见问题」。

> 💡 **配套**：项目里有一份交互式图文教程 [使用指南.html](./使用指南.html)（双击即可打开）。
> 它左侧有悬浮进度图：已完成=绿圈、当前=蓝圈、未完成=白圈，翻到哪一步会自动点亮，还能点圆点跳转，照着它操作比看文字更直观。本 Markdown 版作为文字备份，两者内容一致。

> 🔢 **步骤编号对照**：本版比《使用指南.html》多一个「第 0 步」（先搞懂），所以**本版的第 N 步 = 网页版的第 N+1 步**。例如「填 API Key」：本版第 4 步 = 网页版第 5 步；「开始使用」：本版第 5 步 = 网页版第 6 步。任选一份照做即可，不需要两边对照。

## 第 0 步 先搞懂：这个软件到底是干什么的

### 0.1 一句话说明

面试准备助手（纯文本版）是一个「**面试材料生成工具**」：你把【简历】和【岗位 JD（职位介绍）】喂给它，它调用大模型，自动给你生成一份完整的**面试准备材料**（一个网页文件，可打印、可发给自己复习）。

### 0.2 你需要的 3 样东西

| # | 东西 | 什么时候准备 |
|---|------|--------------|
| 1 | 一台 Windows 电脑 | 现在就有 |
| 2 | 一个或两个大模型服务的「钥匙」API Key | 第 1 步（建议最先注册，有的平台要审核） |
| 3 | 项目文件（从 GitHub 下载） | 第 2 步 |

> **编号说明**：上面 1/2/3 只是"要准备的清单"，不代表操作顺序。实际动手顺序是：第 1 步先注册拿钥匙 → 第 2 步下载项目 → 第 3 步双击启动器（首次自动解压运行环境）→ 第 4 步再把钥匙填进软件。

> **本文统一示例**：下文所有路径、命令都假设——项目解压在 `D:\MS-Agent-Lite`，投递岗位名为 `腾讯-Agent开发实习生`。你的实际路径/岗位名不同没关系，照着样子替换即可。

## 第 1 步 拿到「大模型钥匙」（API Key）

### 1.1 什么是 API Key

想象它是一张「充值卡号 + 密码」。软件调用大模型帮你写材料，需要拿着这把钥匙去服务商那里"买服务"。**钥匙只属于你**，不要给别人。

### 1.2 去哪领（国内常用，不用翻墙）

| 服务商 | 官网 | 说明 |
|--------|------|------|
| 智谱 AI | open.bigmodel.cn | 有免费模型 `glm-4-flash`，新用户送额度，**低成本入门** |
| 硅基流动 | siliconflow.cn | 有免费模型，注册即用 |
| DeepSeek | platform.deepseek.com | 便宜，需充值，模型能力强 |

注册流程：手机号注册 → 实名认证 → 按提示创建 API Key（点"创建/新建 API Key"，复制那串字符）。

### 1.3 你需要记下 4 个信息

| 信息 | 是什么 | 示例（智谱） |
|------|--------|--------------|
| API Key | 一串字符，像密码 | `xxxxxxxx.yyyyyy`（很长） |
| Base URL | 服务商给的接口地址 | `https://open.bigmodel.cn/api/paas/v4/chat/completions` |
| 模型名 | 用哪个模型 | `glm-4-flash` |
| 能力选择 | 界面选「文本能力模型」（默认即可） | 文本能力模型 |

> 建议开一个记事本，把这 4 个信息先粘进去，后面要用。

### 1.4 安全提醒（非常重要）

- API Key = 你的钱和隐私，**不要**发给任何人、**不要**传到群聊 / 博客。
- 泄露了也不怕：回服务商后台点"删除/重置"即可作废旧钥匙。
- 本项目把 Key 存在 `MS-Agent-Lite工程文件/20_执行/config.json` 文件里（后面会提到）。**本机这个文件要保持原样**，软件才能正常工作；将来要把项目传到 GitHub 时，请用项目自带的脱敏副本 `MS-Agent-Lite工程文件/20_执行/config.example.json`（Key 已留空），方法见《GitHub 上传指南》。

## 第 3 步 双击启动软件（首次自动解压运行环境）

> 你**不需要**自己安装 Node.js —— 发布包已内置便携版 Node.js 与依赖包，首次双击启动器会自动解压，之后秒开。

### 3.1 启动（✔ 检查）

**方式一（最简单）：双击启动器**
回到项目根目录（`D:\MS-Agent-Lite`，即解压出来的文件夹），找到 **`启动面试准备助手.bat`**，**双击**它：

- **首次双击**：会自动解压内置的 Node.js 与依赖包（约 1~2 分钟，仅此一次，期间不要关窗口）；
- 解压完成后自动启动本地服务并打开浏览器 `http://localhost:8900/`；
- 若浏览器没自动打开：手动打开浏览器，地址栏输入 `http://127.0.0.1:8900` 回车即可。
- 之后每次启动都是秒开。

**方式二（手动，可选）**：如果你已经自行安装了 Node.js，也可以打开终端，先进入 MS-Agent-Lite工程文件\20_执行 目录，再输入：
```
npm start
```
回车。看到这一行就成功：
```
面试准备助手（纯文本版）服务已启动: http://127.0.0.1:8900（仅本机可访问）
```

### 3.2 打开使用

打开浏览器（Chrome / Edge 都行），地址栏输入：
```
http://127.0.0.1:8900
```
回车，就能看到软件界面了。

> **以后每次使用**：方式一 —— 直接双击根目录「启动面试准备助手.bat」，浏览器没自动打开就手动访问 `http://127.0.0.1:8900`；方式二 —— 进目录后运行 `npm start`。
> **用完想关闭**：方式一启动的软件在后台运行，直接关浏览器即可（下次双击会自动复用或重启服务，不会冲突）；方式二启动的回到终端按 **Ctrl + C**（如果问 Y/N 就按 Y 回车），或直接关掉黑色窗口。

## 第 4 步 把 API Key 填进软件

两种方式任选，**方式 1**（可视化，不容易填错）更方便。

### 方式 1：在网页界面里填

> 这一步要先启动软件。先做第 3 步的启动，打开网页后再回来填：
>
> 1. 网页顶部就是第 1 步「大模型 API Key」卡片：在「选择平台」里选你第 1 步注册的服务商（如智谱 AI），**名称 / Base URL / 模型会自动填好**
> 2. 把第 1 步复制好的 **API Key** 粘贴到「⑥ API Key」输入框
> 3. 点「💾 保存并自检」→ 显示「✓ 已保存并自检通过」、顶部状态条变绿「✓ API Key 已配置成功」就配置成功了
>
> 说明：第 1 步注册的是哪个平台就选哪个；「能力选择」保持默认「文本能力模型」即可（本版只需文本能力，识图由软件内置的本地离线识别自动处理，无需视觉模型）。

### 方式 2：直接改配置文件（备选）

1. 用记事本打开 `D:\MS-Agent-Lite\MS-Agent-Lite工程文件\20_执行\config.json`
2. 找到 `"apiKey": ""`，在空引号中间**粘贴你的 Key**（保留前后的双引号）
3. 按 Ctrl + S 保存
   > 注意：这个文件是 JSON 格式，引号、逗号都不能错。拿不准就回去用方式 1。

### 配置完成自检（✔）

回到网页「设置」里，看到你的 Provider 状态为**可用**；点「自检」出现「✓ 可用」。

## 第 5 步 开始使用（按界面提示走 6 步）

1. **上传简历**：支持 pdf / word(docx) / txt / markdown(md)，**请上传文字版**——扫描件、拍照或图片型 PDF 无法读取，请先用 Word 打开后「另存为」docx（或转成 txt）再上传。把文件拖进框里或点选择。上传后软件先"解析"，解析成功会显示内容预览（说明它读到你的简历了）。
2. **选行业方向（可选）**：如「程序员/开发」，界面会提示这类岗位常搜哪些网站。
3. **填岗位名称**：例如 `腾讯-Agent开发实习生`。注意：生成的文件名就是「岗位名称 + 面试准备」。
4. **填岗位 JD**（直接粘贴文本，更准确、处理更快）：
   - 打开招聘页面，**全选复制** JD 文字，直接粘贴进输入框；或
   - 在「JD 链接」里贴招聘页网址，点「读取到下方」自动填充（辅助方式；若信息读取失败，直接粘贴文本即可）
5. **补充参考网址（可选）**：贴公司官网、面经、技术文章链接。每行一个网址，点「＋ 添加一行网址」可继续加，条数不限。
6. **补充参考信息（可选）**：把面经、公司背景、技术文章、发展方向等**文字**直接粘贴进来（多段用空行隔开，最多 20000 字，输入框下方有字数提示）。比网址更可靠——网页打不开时，把内容复制粘贴到这里照样能用。
7. **点「🚀 一键生成面试材料」**：等待 3~10 分钟（取决于模型速度），期间可看到 8 个文件的生成进度。
8. **完成后**：页面下方出现「内容审核 ✓ 通过」和一个预览窗口；点预览即可阅读完整材料。

打开文件夹（`<岗位名称>` 就是你第 5 步填的岗位名，例如填了 `腾讯-Agent开发实习生`，路径就是）：

## 第 6 步 常见问题（遇到再看）

| 现象 | 原因与解决 |
|------|------------|
| 1. 首次启动解压依赖报错 / 很慢 | 首次启动会自动解压内置的 Node.js 与依赖包（约 1~2 分钟，仅一次，依赖来自发布包内置压缩包、不依赖网络）。若中断或报错，删除 `runtime\node` 与 `MS-Agent-Lite工程文件\20_执行\node_modules` 后重新双击启动器 |
| 2. 启动提示 8900 端口被占用 | 上次没关干净。回到旧终端按 Ctrl + C；或打开任务管理器（Ctrl+Shift+Esc）结束 `node` 进程后重试 |
| 3. 浏览器打不开 http://127.0.0.1:8900 | 确认启动的黑色窗口还开着（没关、没报错）；确认地址是 `http` 不是 `https` |
| 4. 点生成后立刻提示「没有可用 provider」 | 第 4 步没配好：检查 Key 是否粘贴、能力选择是否选了「文本能力模型」、有没有点「保存并自检」 |
| 5. JD 链接读取失败 / 会被封号吗 | 部分网站限制程序读取，属正常现象——直接全选复制 JD 文字粘贴进文本框即可（直接粘贴方式）。本项目只在你点击时读取一次该网址，不会批量抓取，不存在封号风险 |
| 6. 生成很慢 / 某个文件失败 | 正常，免费模型较慢。失败的文件会显示「重试」按钮，点一下即可单独重试 |
| 7. 界面或日志中文乱码 | 不影响使用；若在意，在终端标题栏右键 → 属性 → 字体选「新宋体」或 Lucida Console |
| 8. 审核提示 WARN | 说明生成内容里可能有数字 / 项目与你的简历对不上，按界面提示人工修正一下再重新生成 |
| 9. 想上传项目到 GitHub | 不要动本机的 `MS-Agent-Lite工程文件/20_执行/config.json`（动了软件就用不了）。上传时用脱敏副本 `config.example.json` 代替它，方法见《GitHub 上传指南》 |
