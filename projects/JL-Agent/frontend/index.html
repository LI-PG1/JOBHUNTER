    如何获取 Tavily API Key？（点击展开教程）
    1. 打开官方平台 app.tavily.com ↗，注册或登录账号；
    2. 进入 Dashboard（控制台），找到左侧「API Keys」页面；
    3. 点击「Create API Key」生成以 tvly- 开头的密钥；
    4. 复制密钥粘贴到上方输入框，点击「保存搜索 Key」即启用联网搜索。
