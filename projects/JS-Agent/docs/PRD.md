# JS-Agent PRD（岗位匹配助手 · v0.2 LLM-Agent 版）

> 独立项目，非 MS-Agent 衍生产品。版本 0.2.0 · 2026-08-11

## 1. 背景与问题

用户（2027 届 AI 大模型方向硕士，技能双线：应用 + 推理）需要一份**可执行、有依据、不过时**的岗位投递清单。纯规则引擎无法完成深度搜索与判断；人工逐站搜集费时且易过期。

**为什么做**：把"搜岗位 + 判匹配 + 写清单"交给大模型自主完成，用户只提供 API Key 与画像。

## 2. 目标与成功指标

- 收录准确率：Gate2 判定与人工复核一致率 ≥ 90%
- 时效保证：收录岗位时效标注覆盖率 100%，超期自动排除
- 防编造：Gate3 质检拦截无来源岗位，0 条无来源输出
- 可执行：清单含来源链接、JD 拆解、投递动作，可直接用于投递

## 3. 目标用户与场景

- 2027 届硕士，AI 大模型方向（Agent/RAG + vLLM/量化/推理优化）
- 目标城市：深圳为主，可切换
- 场景：投递前生成匹配清单 / 定期增量更新 / 单岗位 JD 深度拆解

## 5. 功能描述与验收标准

### F3 Agent 循环

**功能**：画像锚定 → 规划（≥3 轮搜索、覆盖 3 类来源）→ 深度搜索（动态轮次 + 收敛）→ 洗涤 → 收录判定 → 扩散（≥90% 自动扩散）→ 排序 → 生成 → 质检 → 保存。

**验收（Given-When-Then）**：
- 当任务启动且已配置 Key 时，页面显示实时进度，最终输出结果清单
- 当任务失败（无 Key / 搜索全挂）时，返回明确错误信息与失败阶段

### F4 三层约束网关

**验收**：
- 当画像技能名未命中本体时，该技能被忽略并告警（防幻觉）
- 当岗位匹配度 ≥80% 时收录；60-80% 时标注补足技能；<60% 时排除
- 当岗位缺少来源链接时，禁止输出（防编造）

### F6 插件双按钮

**验收**：点击「一键配置」后按钮置灰显示"配置中..."直至完成；「一键卸载」同理；状态实时刷新。

## 6. NON-GOAL（明确不做）

- 不做投递进度追踪（后续版本）
- 不做厂商自定义（预设 15 家，不允许自定义）
- 不做多城市并行（城市切换制，规则库可扩展）
- 不做成本统计（v0.4 已移除）
- 不做商业化/付费功能（开源定位）

## 7. 匹配规则（Gate2）

- 技能匹配：按技能本体 id（非名称字符串），ASCII 词条词边界匹配
- 阈值：≥80% 收录 / 60-80% 补足 / <60% 排除 / ≥90% 自动扩散
- 企业五档：央企 > 国企 > 大型 > 中型（独角兽归此）> 小型，优先顺序判定
- 时效：updated_at 距今 > fresh_days（strict=60 天）自动排除
- 打分交叉验证：LLM 打分与规则打分偏差 >15 分触发复核

## 8. 数据源优先级

- 搜索：智谱 web_search → Tavily → ddgs（免 Key）→ Playwright 兜底（需确认）
- 抓取：Jina Reader → Trafilatura → urllib 直连
- 收录岗位必须带来源链接；事实与推断分离（薪资/估值为"参考"）

## 9. 风险与依赖

- 依赖用户 API Key 的模型能力（搜索与判断质量随模型浮动）→ 用三层网关做确定性兜底
- 免 Key 搜索通道（ddgs）处于灰区 → 插件面板显式标注，有限授权
- Playwright 体积大（~150MB）→ 仅兜底，需用户确认后安装

## 10. 版本规划

- **v0.2（本版）**：LLM-Agent 骨架 + 三层网关 + 控制台 + 插件系统 + 四步流程前端
- **v0.3**：流式进度、Key 预检快速失败、ADRs 归档、AI 对抗测试
- **v0.4+**：投递追踪、多城市、评测集持续积累
